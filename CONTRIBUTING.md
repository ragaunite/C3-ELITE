# Contributing to C³ Elite

Thank you for your interest in contributing.

## Development Setup

```bash
git clone https://github.com/yourusername/c3-elite.git

cd c3-elite

npm install

npm run dev
```

## Pull Request Process

1. Fork Repository
2. Create Feature Branch
3. Commit Changes
4. Push Branch
5. Create Pull Request

## Coding Standards

- Use React Functional Components
- Use Hooks
- Write Clean Code
- Use ESLint
